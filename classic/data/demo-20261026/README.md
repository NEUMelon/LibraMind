## 学生数据

学号为 8 位数字，前 4 位表示入学年份，后 4 位为本批随机且唯一的演示序号。不推断学院或专业编码。避开已有 20 个学号以及用户本人学号。固定随机种子 20261026，确保生成过程可复现。姓名按常见姓氏和名字组合生成，允许同名，不把姓名当成唯一键。原有 20 个演示学生的资料没有更改。

总计 1,000 个不同且通过校验位检查的 ISBN，以中文书和中译本为主。每个 ISBN 在本项目生成一册馆藏，书号使用 CN-ISBN13；这是演示馆藏号，不代表任何图书馆的真实库存。

books.json 保留 ISBN、出版社、译者（源表有独立字段时）、来源地址、文件名、原行号或 PDF 页码。传统版数据库仍使用课程要求的现有字段，没有扩表；完整外部元数据不塞入书名或版本号。

版次优先采用源表的明确版次或书名中的“第几版”等字样；没有依据时写“版次未注明”，不把出版年份、印次当成版次。部分图灵版本出自 2012 年旧目录，并非最新版本。新选书目排除文创、日历以及明显非中文条目。

原精选 500 中有 15 条作者字段含不可见的 U+0007 控制字符；已去除，修改前后值记入 validation.json，其余书目事实保留。来源原文件没有修改。书目只是公开的基本编目事实，没有复制正文、简介、书评或封面。

## 文件与运行

- books.json / students.json：书目完整元数据与模拟学生。
- books.tsv / students.tsv：JDBC 导入中间文件，UTF-8，以 # 开头的行为说明。
- validation.json：数量、分布、源文件哈希、清洗记录。
- import-result.json：本次实际导入与重复执行的结果。

在项目根目录运行 scripts/import-demo-data.ps1。它读取本机 config/db.properties，不输出密码；导入前在 .runtime/data-backups/ 下保存三张表的完整快照。TSV 快照中 \\N 表示 NULL，反斜线、制表符和换行分别转义。快照保留内部主键和原字段。

导入使用 PreparedStatement 和一个事务：同编号且字段一致则跳过，同编号不同资料则报错并整批回滚，不使用 INSERT IGNORE、REPLACE、清表或覆盖。相同批次再次执行已验证新增 0 行。业务 Java、JSP 和数据库结构未改变，不需要重新构建页面或重启 Tomcat，刷新即可看到新数据。

tools/prepare_demo_data.py 是本批整理过程脚本，依赖本机原始书目、用户规则文件和导入前快照；日常导入不需要运行它。原下载 Excel 保存在 .runtime/catalog-sources/，旧数据包原始来源保留在用户原目录。
